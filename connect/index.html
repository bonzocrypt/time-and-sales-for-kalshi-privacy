TIME & SALES for KalshiPrivate, local setup

CONNECT YOUR PHONE

Your key. One scan.

Set up streaming without typing a private key on your phone.

1 Create your Kalshi key

On your computer, open Kalshi’s account settings → API Keys → Create New API Key.

Choose RSA instead of Ed25519. Enable Read all data only and leave trading and write permissions off. Download the private-key text file and copy its Key ID.

Open Kalshi account settings ↗

2 Create your setup code

Choose the file on this computer. It is read here, not uploaded.

3 Scan from the phone app

In Time & Sales, open Settings → Scan setup code. Scan here, then tap Connect & open Markets.

▦

Your setup code appears here

Complete the two fields on the left.

Requires Android app version 1.0.4 or later.

This code contains your private key. Do not screenshot, share, or display it to others.

After your phone confirms the connection, clear the code and close this page. Clearing the code does not revoke your Kalshi key.

Credentials stay with you

QR generation runs in your browser. This page does not upload your key, save it in browser storage, or include it in a link. The phone checks the connection directly with Kalshi and saves credentials in secure device storage.

Opened this on your phone?

Send yourself this public link and open it on your computer. No key is included.

Need another option? Use File import & manual setup in the app. Keep a secure backup of your key; Kalshi cannot show it again.
